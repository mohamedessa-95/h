# مكتب المحاماة

## Windows Build

هذا المشروع مخصص لبناء نسخة Windows من البرنامج.

### Storage
يحتوي المشروع على مجلد `storage` لحفظ بيانات البرنامج محليًا:
- `storage/documents`
- `storage/backup`

تم وضع ملفات `.gitkeep` للحفاظ على المجلدات الفارغة عند رفع المشروع إلى GitHub.

### ملاحظات
- لا تحذف مجلد `storage`.
- بعد البناء، استخدم ملف الـSetup الناتج لتثبيت البرنامج.
