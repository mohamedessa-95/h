# التخزين الموحد - النسخة التنفيذية

تم ربط البرنامج فعليًا بطبقة SQLite محلية داخل `office-data/office.sqlite`، مع مجلد `office-data/documents` للملفات ومجلد `office-data/backups` للنسخ الاحتياطية الكاملة.

عند أول تشغيل: إذا لم توجد قاعدة SQLite، يقرأ البرنامج البيانات القديمة من localStorage وينقلها إلى SQLite، ويحاول نقل ملفات IndexedDB إلى التخزين الموحد. لا يتم حذف البيانات القديمة تلقائيًا.

النسخة الاحتياطية الكاملة تحتوي على قاعدة البيانات + كل المستندات/التوكيلات + بيانات فهرس الملفات في ملف ZIP واحد. الاستعادة تستبدل البيانات الحالية بالنسخة المختارة.

يجب اختبار النسخة على جهاز Windows فعلي بعد تثبيت dependencies وبناء EXE قبل توزيعها تجاريًا.
